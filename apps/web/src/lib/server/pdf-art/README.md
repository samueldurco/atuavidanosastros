# Gravuras dos PDFs gratuitos

As cinco imagens são derivações em PNG das gravuras já aprovadas no MVP e usadas na home. A exportação determinística redimensiona de 1254 para 416 pixels com Lanczos3: 288 ppi na aplicação de 104 pontos do PDF. Preserva composição, proporção, cores e transparência; não há geração, redesenho ou recorte. Essa resolução mantém a qualidade de impressão e o limite de tamanho do arquivo. O formato PNG permite incorporação local pelo `pdf-lib`, sem buscar imagens durante o download.

`manifest.json` registra o caminho de cada fonte, SHA-256 de origem e saída, tamanho e operação de exportação. Os direitos e o estado de aprovação permanecem os das artes ATVNA de origem em `static/brand/mvp/assets/revisao`.

Mapeamento: mandala para Meu Céu; bússola para Propósito e Prosperidade; flor para Amor e Relações; cartas para Tarot; gravura de sonhos para Sonhos e Símbolos. O Horóscopo é editorial e não participa deste exportador de resultados pessoais.
