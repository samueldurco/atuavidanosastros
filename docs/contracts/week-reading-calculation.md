# Semana — experimental seven-sample contract

`week-reading` uses `atv-week-reading-calculation/1.0.0`. This partial, experimental E1 base contains seven consecutive Gregorian dates, each sampled at exactly **12:00 UTC**, and one unchanged natal basis. The first date must be within 1900-01-01–2099-12-25 so all seven dates remain in the existing engine range. It does not establish seven local days, local noon or complete temporal coverage.

The calculator captures validated input before awaiting a provider. All seven dates and the civil/UTC natal correspondence are checked before any provider call. A request-local cache obtains one natal chart and seven sample charts (eight calls), with defensive copies and cancellation checks around each awaited operation. Concurrent executions share no natal cache. The synthetic sample coordinates are an internal geocentric reference, not an inferred current location.

Seven context-free `date-reading` snapshots retain their original contracts and provenances. Their dates must be ordered and distinct, and their complete natal basis must match. The outer projection contains 88 unique facts: one range, ten natal positions and seven groups of ten sample positions plus a sample instant. Optional personal context adds exactly one final reported fact, sourced from `input.context`, preserving the submitted text. It is nonblank, well-formed Unicode, at most 1,200 UTF-16 units, and excludes disallowed C0/C1/DEL controls. Context does not affect geometry.

`validWeekReadingProjection` validates the original JSON-compatible snapshot and reconstructs its entire expected projection without calling the provider. It rejects missing/extra fields, non-JSON metadata, changed facts, ranges, contracts, provenances, positions, limits, context and ordering. This proves persisted coherence only; source authentication, request binding, accuracy and engine homologation require their separate trusted boundaries and evidence.

Preparation `atv-product-editorial-evidence/1.33.0` invokes this guard on the original persisted Week snapshot before editorial admission, including fact metadata omitted by generic normalization. Corrupt snapshots return `calculation_invalid`. Only the trusted `week-reading` product selects `atv-week-reading-editorial/1.0.0`, admitting all 88/89 facts unchanged. Unprofiled envelopes retain the generic 40-fact bound; the caller cannot supply a profile through the persisted calculation.

The editorial profile requires eight ordered hypotheses: shared natal basis and one per daily sample. Each references the range, all natal facts and optional reported context; daily hypotheses also reference all eleven facts of their own sample and name its exact date. One synthesis joins all eight roles, three distinct practical questions preserve autonomy, relations remain empty and four literal limitations preserve partial scope, UTC sampling, absent calculations and absent calendar/continuity. The AI validates topology; the Worker validates original geometry and provenance. Neither check certifies semantic usefulness or engine accuracy.

Profile transport bounds are 89 facts, sources up to 300 characters, input JSON up to 60,000 characters, output up to 22,000 characters/4,500 tokens, eight claims and zero relations. Each claim remains within the unchanged 40-reference schema. These bounds apply only to this profile; generic/free budgets, quota reservation, default-disabled gateway, data-class restrictions and commercial/release authority remain unchanged. Input over the bound is refused before quota reservation or provider work. Prompt version is `atv-editorial/1.0.19`. Synthetic fixtures can yield `needs_editorial_review` and a bound digest, with publication blocked; approved useful interpretation and legitimate review are still required.

Registration requires `experimentalWeekBase: true`; processor selection additionally requires the existing explicit `enabledProducts` allowlist. Both are internal server decisions. The default thirteen-base composition, generic 400-fact/200000-byte calculation bounds, free-tier AI budgets, publication gates and spend remain unchanged. The base has empty aspects, events and windows, and produces no interpretation, timing search, intensity, current timezone/location, calendar, reminders or alerts.
